# Faital Bluetooth Speaker — ESP-IDF

Прошивка Bluetooth-колонки на ESP32 із зовнішнім ЦАП PCM5102A,
фізичним керуванням відтворенням, індикацією стану та контролем батареї.

## Цільові можливості

- Приймання стереоаудіо з телефона через Bluetooth Classic A2DP.
- Виведення звуку через I2S на PCM5102A.
- Керування гучністю енкодером і синхронізація з телефоном через AVRCP.
- Play/Pause, Next/Previous та окрема кнопка підключення Bluetooth.
- Автоматичне перепідключення до останнього пристрою.
- Вимірювання напруги батареї 3S2P, оцінка заряду та попередження LOW BATTERY.
- Відображення батареї на OLED SSD1306 і стану колонки на WS2812.

Цільовий аудіотракт:

```text
Телефон → Bluetooth A2DP → PCM → I2S → PCM5102A → підсилювач
```

## Апаратна конфігурація

Плата — ESP32 DOIT DevKit V1, target `esp32`, налаштування flash — 4 MiB.
Призначення GPIO збережені з робочої Arduino-прошивки.

| Функція | GPIO |
| --- | --- |
| I2S BCK / WS / DATA | 26 / 25 / 19 |
| EC11 A / B / кнопка | 32 / 33 / 18 |
| Previous / Next / Bluetooth | 13 / 14 / 23 |
| Батарея, ADC1 | 34 |
| OLED SDA / SCL | 21 / 22 |
| WS2812, 8 світлодіодів | 27 |
| Status LED | 2 |

OLED: SSD1306 128×64, I²C-адреса `0x3C`.
Кнопки й енкодер використовують внутрішні підтягування та активний LOW.
Параметри еталонного вимірювання батареї: дільник 150/30 кОм, коефіцієнт
калібрування 0,9880. GPIO2 показує роботу головного циклу коротким спалахом щосекунди.

## Середовище та компоненти

| Налаштування | Значення |
| --- | --- |
| Система збірки | PlatformIO |
| Environment | `esp32doit-devkit-v1` |
| Платформа | `espressif32@7.1.3` |
| Framework | ESP-IDF 6.1.0 |
| Пакет framework | `platformio/framework-espidf@4.60100.0` |
| Мова застосунку | C++ |
| UART | 115200 baud |
| CPU | 240 MHz |

Bluetooth A2DP та AVRCP реалізовані бібліотекою **ESP32-A2DP v1.8.11** —
тією самою, що в Arduino-еталоні, зібраною як native ESP-IDF component.
Вбудований SBC-декодер Bluedroid видає PCM; невеликий адаптер передає його
штатному драйверу `esp_driver_i2s`. Arduino framework і AudioTools не потрібні.
Нелінійна крива гучності з ESP32-A2DP збережена.

Копія вихідних файлів бібліотеки зафіксована в репозиторії разом із ліцензією.
Версія, походження та параметри інтеграції описані в
[components/esp32_a2dp/README.md](components/esp32_a2dp/README.md).
GPIO-кнопки обслуговує native компонент
[espressif/button 4.2.3](https://components.espressif.com/components/espressif/button/versions/4.2.3).
Component Manager завантажує його за `src/idf_component.yml`; точні версії,
включно з допоміжним `espressif/cmake_utilities`, зафіксовані в `dependencies.lock`.
Енкодер обслуговує штатний апаратний драйвер `esp_driver_pcnt`: один канал
у режимі half-quadrature, два відліки на фіксований крок. Фільтр 12788 нс
відповідає 1023 тактам APB у вихідному проєкті. Накопичення при переповненні
апаратного лічильника виконує драйвер ESP-IDF.
Батарею вимірює штатний `esp_adc` у режимі oneshot з калібруванням.
OLED обслуговує [chill-sam/ssd1306 1.1.2](https://components.espressif.com/components/chill-sam/ssd1306/versions/1.1.2/readme)
із готовими шрифтом і графічними функціями. Component Manager завантажує
зафіксований Git-коміт цієї версії за маніфестом `components/speaker_battery`;
Git використаний через вкладені `dist`-каталоги в архіві Registry, які перевищують
ліміт довжини шляхів Windows.
Інші основні компоненти — GPIO, FreeRTOS, NVS, esp_timer, log, esp_system,
esp_hw_support, esp_app_format, spi_flash та esp_partition.

## Bluetooth і аудіовихід

Назва пристрою — **Faital Bluetooth Speaker**. Підключення обирають у Bluetooth
налаштуваннях телефона. Підтримується A2DP з кодеком SBC; гучність телефона
передається через AVRCP Absolute Volume та застосовується до PCM.
Діапазон — 0..127, початкове значення до команди телефона — 64.
Один фіксований крок енкодера змінює гучність на 4; за годинниковою
стрілкою — збільшує. Напрямок можна змінити через `ENCODER_REVERSED`
у параметрах збірки. Гучність змінюється від останнього актуального рівня,
встановленого телефоном або енкодером. Синхронізація індикатора на телефоні
залежить від підтримки AVRCP Absolute Volume цим пристроєм.

Кнопка енкодера **GPIO18** перемикає Play/Pause; **GPIO13** надсилає Previous,
**GPIO14** — Next. Реакція на Previous, зокрема повернення на початок поточного
треку, визначається програвачем. Play/Pause використовує підтверджений стан
AVRCP, а за його відсутності — стан аудіопотоку A2DP. Короткі натискання
спрацьовують після відпускання, антидребезг — 40 мс. Утримання понад 800 мс
не має дії. Від'єднаний пристрій не накопичує команди керування.

I2S працює як master у форматі Philips, 16 біт, стерео, з початковою частотою
44,1 кГц. Частота змінюється відповідно до узгодженого SBC-потоку;
моно подається однаково в обидва канали. Під час паузи на виході — тиша.
MCLK не виводиться на GPIO.

Після запуску колонка намагається підключитися до останнього телефона.
При неочікуваній втраті зв'язку також виконує до п'яти спроб; якщо вони
не вдалися — залишається доступною для підключення з телефона.
Навмисне від'єднання через Bluetooth-меню телефона не запускає повторні спроби.

Коротке натискання й відпускання кнопки **Bluetooth на GPIO23** вмикає
ручне парування: зупиняє повторні вихідні спроби, завершує поточне з'єднання
та відкриває колонку для підключення. Останній підключений телефон
запам'ятовується для наступних запусків. Довге утримання не має окремої дії.
Раніше спарений телефон також може сам підключитися в цьому режимі.

Поточна реалізація містить аудіоприймання, керування гучністю з телефона
та енкодера, медіакнопки, перепідключення, кнопку Bluetooth, heartbeat,
вимірювання батареї та OLED. Індикація WS2812 запланована окремо.
Bluetooth-зв'язки зберігаються в NVS; автоматичного очищення NVS немає.

## Батарея та OLED

Напруга акумулятора 3S2P вимірюється на GPIO34 через дільник 150/30 кОм:
`Vbat = Vadc × 6 × 0.9880`. Калібрування ADC використовує заводські дані eFuse;
за їх відсутності — опорне значення 1100 мВ з повідомленням у лог.
Коефіцієнт і зміщення вимірювання налаштовуються в `src/app_config.h`.

Виміри виконуються приблизно кожні 10 мс. Із 20 значень відкидаються два
найменші й два найбільші, решта усереднюються; згладжування EMA має коефіцієнт
0,20. Оновлення результату — раз на секунду. Заряд оцінюється за кривою напруги
3S Li-ion; навантаження підсилювача може тимчасово зменшувати показник.

OLED показує відсоток, напругу та значок батареї. При напрузі <=10,8 В
з'являється **LOW BATTERY**, значок блимає з інтервалом 500 мс.
Попередження зникає при >=11,1 В. Поза діапазоном 8,0–13,2 В або при
помилці вимірювання відображається **BATTERY ERROR**. Це індикація;
прошивка не відключає живлення акумулятора.

Дисплей оновлюється окремою задачею через native I²C. Передавання мають
обмежений час очікування; відсутній OLED або помилка його шини не зупиняють
аудіо, кнопки чи вимірювання батареї. Після помилки OLED повторно ініціалізується
лише під час наступного запуску. Деталі інтеграції — у
[components/speaker_battery/README.md](components/speaker_battery/README.md).

Згенерований `sdkconfig.esp32doit-devkit-v1` відстежується Git;
його оновлюють інструменти конфігурації та збірки.
Скрипт PlatformIO додає залежності `memory.ld` від `sdkconfig.h` та `ld.common`,
щоб резервування пам'яті Bluetooth відповідало поточній конфігурації.

Flash містить NVS 20 KiB з адреси `0x9000`, PHY 4 KiB з `0xF000`
та factory app 3 MiB з `0x10000`. Решта простору не розмічена.
Поточна таблиця не передбачає OTA чи файлової системи.

## Збірка та запуск

Відкрити корінь проєкту у VS Code з PlatformIO і вибрати
`Project Tasks → esp32doit-devkit-v1`.
Доступні стандартні дії `Build`, `Upload` та `Monitor`.

Еквівалентні команди в терміналі PlatformIO з кореня проєкту:

```powershell
pio run -e esp32doit-devkit-v1
pio run -e esp32doit-devkit-v1 -t upload --upload-port COMx
pio device monitor -e esp32doit-devkit-v1 --port COMx --baud 115200
```

`COMx` потрібно замінити фактичним портом плати.
